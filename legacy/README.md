# legacy

`copy-as-markdown-v2.0.6-clean/` 是上游仓库里未经修改的原始快照，仅用于对照排查过程
（见 `../REPORT.md`）。

**不要**把这里的文件加载到 Chrome，也不要打包上架 —— 它包含这些问题：

- 根目录结构缺失导致加载失败率高
- 右键菜单不随设置变化，关掉后菜单永久消失
- 老标签页点击后静默失败
- 段落 / 列表 / `<br>` / 代码块 / 表格被拼成一坨
- `modules/` 是死代码，且 `modules/settings.js` 一调用就 `ReferenceError`
- 三个图标都是纯色占位图

确认新版稳定后，可以整个目录删除。
