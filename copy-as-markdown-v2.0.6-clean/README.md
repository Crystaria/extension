# Copy as Markdown

A lightweight Chrome extension that converts selected text to Markdown format with a single right-click.

## Features

- 🔗 **Link Conversion**: Automatically convert links to `[text](url)` format
- 🖼️ **Image Support**: Convert images to `![alt](url)` format
- 📝 **Heading Detection**: Auto-convert H1/H2/H3 to #/##/###
- ✨ **Format Preservation**: Keep bold (`**text**`) and italic (`*text*`)
- ⚙️ **Customizable**: 6 settings to tailor to your needs
- 🔒 **Privacy First**: 100% local processing, no tracking
- ⚡ **Lightweight**: <200 lines of core code

## Usage

1. Select any text on a webpage
2. Right-click and choose "Copy as Markdown"
3. Paste anywhere (Obsidian, Notion, GitHub, etc.)

## Settings

Click the extension icon to access settings:
- Enable/Disable extension
- Toggle link conversion
- Toggle image conversion
- Toggle heading conversion
- Preserve formatting
- Show/hide notifications

## Permissions

- contextMenus - Add right-click menu option
- storage - Save your settings locally
- activeTab - Access selected text
- scripting - Inject conversion logic
- clipboardWrite - Copy to clipboard

**No unnecessary permissions. No tracking. No ads.**
